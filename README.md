### 🚀 Featured Project — DriverGuard

> Real-time vehicle safety monitor using MediaPipe + YOLOv8-nano

- 🎯 Detects driver drowsiness (EAR/MAR/head-pose) + road damage across 5 classes
- ⚡ Runs at **20–28 FPS** with alert latency under **750ms**
- 📉 Per-driver auto-calibration reduced false-trigger rate by ~**60%**
- 🗺️ Live Flask + Socket.IO dashboard with GPS hazard mapping & session analytics
- 🔧 Deploying on **Raspberry Pi 5** with IR camera & NEO-6M GPS
